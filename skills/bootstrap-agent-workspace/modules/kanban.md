# 排期清单模块

> 仅在用户选择“排期清单”时加载。

## 生成

将 `templates/kanban/BACKLOG.md.template` 复制到项目根 `BACKLOG.md`，替换日期占位符。已有文件默认升级，不覆盖用户内容。

## 职责

- 只保存未完成事项。
- 每项包含编号、优先级、现状、原因、方案和收益。
- 完成项从看板移除。
- 闭环后新建 `decisions/` 决策文件（引用排期编号）并追加 `_INDEX.md` 索引行；决策文件是闭环事实唯一来源。

## 联动

若同时选择核心文档：

- 在 `AGENTS.md` 文档目录树增加排期清单。
- 在 `AGENTS.md` 的文档职责中说明“待办进、完成出、闭环进 decisions/”。

未选择核心文档时只生成排期清单，不擅自创建其他文档。
