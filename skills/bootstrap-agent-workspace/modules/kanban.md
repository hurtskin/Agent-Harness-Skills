# 排期清单模块

> 仅在用户选择“排期清单”时加载。

## 生成

将 `templates/kanban/排期清单.md.template` 复制到项目根 `排期清单.md`，替换日期占位符。已有文件默认升级，不覆盖用户内容。

## 职责

- 只保存未完成事项。
- 每项包含编号、优先级、现状、原因、方案和收益。
- 完成项从看板移除。
- 闭环事实追加到 `决策日志.md`，并引用排期编号。

## 联动

若同时选择核心文档：

- 在 `AGENTS.md` 文档目录树增加排期清单。
- 在 soul 的文档职责中说明“待办进、完成出、闭环进决策日志”。

未选择核心文档时只生成排期清单，不擅自创建其他文档。
