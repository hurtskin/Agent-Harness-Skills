# `<Tool Name>` 适配器示例

> 本文件是新增 Hermes 工具适配器的结构示例，不是已注册适配器。复制后重命名为 `adapters/<tool-slug>.md`，删除所有占位说明，并按客户端真实能力填写；不得直接把示例注册为正式支持。

## 定位

说明工具的准确产品名、适用版本和适配目标。若同名产品不唯一，列出区分依据，并规定无法确定时必须询问用户。

## 检测信号

按证据强弱列出可验证信号，例如：

- 当前运行环境明确声明为 `<Tool Name>`。
- 项目存在工具专属配置 `<tool-config>`。
- 项目存在工具专属入口 `<tool-entry>`。
- 只有通用 `AGENTS.md` 时不得反推具体工具。

多个候选冲突或证据不足时，确认工具名称、版本和自动加载入口，不得猜测。

## 官方入口

记录经过验证的自动加载行为：

- 默认入口：`<entry-path>`。
- 目录继承或覆盖规则：`<inheritance-rules>`。
- Markdown 引用能力：`<reference-support>`。
- 条件规则能力：`<conditional-loading-support>`。
- 入口优先级：`<precedence>`。

若没有统一入口，明确写出“当前未确认统一入口，必须依据运行时证据或用户确认”，不要省略本节。

## 生成策略

1. 本适配器只处理 `<Tool Name>` 原生入口和配置，不创建 `AGENTS.md`、soul、决策日志、排期或 lessons 等公共事实源。
2. 执行前消费公共流程形成的 `available_artifacts`，只引用已经存在或由本次所选模块确定生成的文件。
3. 没有可用公共文件时，不生成空壳入口；已有入口默认保留，不追加失效引用。
4. P0 只包含客户端必须常驻的最小入口或差异规则；支持引用时优先引用已有 P0 事实源，不复制全文。
5. P1 只建立路径索引或经确认的条件加载规则；能力不明时使用薄入口列出路径和读取条件。
6. `决策日志.md`、`.trae/rules/lessons-learned.md` 和归档 Spec 保持 P2，不加入无条件自动加载链。
7. 同一事实源只保留一条默认自动加载路径；客户端已经原生加载 `AGENTS.md` 时，不通过另一配置重复导入。
8. 只有 `AGENTS.md` 已存在或本次核心流程将生成时，才登记工具适配状态；否则只在执行结果中报告。
9. 若支持 changelog-rag MCP，说明客户端原生配置格式、增量合并方式和模板路径；不支持时不要生成相关配置。

## 兼容边界

- 记录已确认的最低版本、平台差异和配置格式限制。
- 不宣称客户端支持尚未验证的引用、条件规则、MCP 或自动发现能力。
- 修改已有机器配置时保留未知字段、注释和原有格式，不用模板覆盖整个文件。
- 客户端专属权限、Agent 或模型配置不属于公共事实，只有用户明确要求时才调整。
- 冲突按“客户端不可绕过约束 > 项目安全红线 > 当前已确认 Spec / 任务约束 > 索引与历史”处理；无法消解时停止并询问。

## 校验

- 只校验实际生成或实际采用的入口；未生成入口时，不把缺少入口判为独立模块初始化失败。
- 所有引用目标都属于 `available_artifacts`，并且已经存在或确定由所选模块生成。
- P0 保持精简，P1 有读取条件，P2 未进入无条件自动加载链。
- 同一公共事实源没有通过原生入口、引用和配置重复加载。
- 未确认入口或能力时，适配状态为 `pending-confirmation`。
- `AGENTS.md` 可用时记录工具、入口、状态、来源和最后确认日期；不可用时只在执行结果中报告。
- 若生成客户端配置，验证语法、占位符替换、路径存在性和增量合并结果。
