# changelog-rag (template)

> Local MCP server for semantic retrieval over `AGENTS.md` decision changelog.
> This is the **template** copied by `bootstrap-agent-workspace` skill v3.
> For the full documentation, see [lessons-learned.md §19 / §20] in the project.

## What it does

Two MCP tools (over stdio) let an agent pull only the decision-log entries relevant
to the current task, instead of reading the entire `AGENTS.md`:

| Tool | Purpose |
|---|---|
| `list_recent_changelog(limit=N)` | Returns the N most recent entries (no embedding) |
| `load_relevant_changelog(keywords=[...], limit=K)` | Returns top-K entries ranked by semantic similarity |

## Setup (after skill copies this template)

This package is a member of the shared `tools/` uv workspace. Run all environment commands from `tools/`; do not create a package-local `.venv` or `uv.lock`.

```bash
cd tools
uv sync --all-packages --all-extras
uv run python -c "from sentence_transformers import SentenceTransformer; SentenceTransformer('BAAI/bge-small-en-v1.5')"
uv run pytest changelog_rag/tests/
```

## Wire into your IDE

Add the JSON from `.trae/mcp-config.json` (auto-generated by bootstrap skill) to
your IDE's MCP servers. Restart the IDE.

After code changes, disable → enable the server in the IDE MCP panel
(IDE does not auto-restart stdio servers — see lessons §20).
